# Haafidher Work Plan

## Objective
Build a Quran memorisation application around the Haafidher learning engine.

## Phase 1 - Core Engine
- Passage model
- Memorisation states
- Review scheduling
- Morning and evening sessions
- Snowball progression logic

## Phase 2 - Quran Layer
- Quran data integration
- Reading navigation
- Passage selection

## Phase 3 - Learning Features
- New memorisation
- Consolidation
- Revision cycles
- Weak passage recovery

## Phase 4 - Tafsir and Content
- Tafsir data layer
- Verse-linked explanations
- Reading integration

## Phase 5 - Application
- Android UI
- Local storage
- Statistics
- Testing
